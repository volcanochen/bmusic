# BMusic 发布包（release）

本目录存放可直接下载安装的 APK 成品，随仓库一起推送，方便从 GitHub 直接获取。

## 当前版本

- **版本号**：v1.0.31（`versionName 1.0.31` / `versionCode 32`）
- **包名**：`com.volcano.bmusic`
- **最低系统**：Android 7.0（API 24）
- **目标系统**：Android 14（API 34）
- **体积**：约 286 KB（零第三方依赖，纯 Android SDK 构建；含 ZXing QR 编码/解码子集）
- **APK 文件**：[`bmusic.apk`](bmusic.apk)（本目录内，始终为最新版）

### v1.0.26 更新内容
- **桌面小组件新增上一首 / 下一首**：2×2 组件改为「左上一首 · 中播放暂停 · 右下一首」三键布局；左右控件用 `weight` 撑满剩余宽度形成大点击热区，中间仍是原来的粉色圆钮。点歌名/歌手或空白处依旧进播放页
  - 桌面组件基于 `RemoteViews`，系统**不支持触摸手势**（左右滑动会被桌面当成翻页），因此用「点击左右热区」替代滑动；小组件上点上一首会**无条件切歌**（不套用通知栏「播放超过 4 秒先回到开头」的规则）
  - 三个 PendingIntent 使用不同 requestCode 并走 `getForegroundService`（Android 8+ 后台启动限制）
- **切到其他视频 / App 后能续回来播放（重点）**
  - 根因：旧逻辑在所有焦点丢失分支都调 `pause()`，而 `pause()` 会 `abandonAudioFocus()` —— 一旦放弃注册，对方释放焦点时系统再也不会回调 `AUDIOFOCUS_GAIN`；同时 GAIN 分支本来就是空的
  - 现在区分「用户主动暂停」与「被别的 App 抢占焦点」：被动中断只暂停、**保留焦点注册**，GAIN 时自动从断点续播；`AUDIOFOCUS_LOSS_TRANSIENT_CAN_DUCK` 改为压低音量而不是静音不动
  - Android 8+ 改用 `AudioFocusRequest` 并开启 `setAcceptsDelayedFocusGain(true)`：若点播放时焦点正被视频占着，动作挂起等对方释放再执行，不会两个 App 同时出声
  - 每 5 秒把播放位置落盘（`last_pos` / `last_pos_id`）；服务被系统回收后重启，`restore()` 带上断点并在 `onPrepared` 里 `seekTo`，点播放即从原位置继续。切歌时清除断点
  - `MainActivity` / `PlayerActivity` 的 `onResume` 加兜底：若上次确实是被打断且服务还活着，重新申请焦点续播；用户主动暂停过或没启动过服务都不会自动出声
### v1.0.25 更新内容
- **修复「请求被拦截(-412)」导致无法播放 / 缓存失败（重点）**
  - 根因：旧逻辑在 WBI 签名请求失败后会再发一次**无签名**请求、Referer 固定首页、且缺少成对的 `buvid3/buvid4` 设备指纹，正好命中 B 站 Web 风控；最终错误还来自那次无签名请求
  - 现在：持久化设备身份（spi 下发 `buvid3/buvid4` + `b_nut/buvid_fp/_uuid`）、换取 `bili_ticket`、完整浏览器请求头（UA / sec-ch-ua / Sec-Fetch-*）、**视频页精确 Referer**、统一 WBI 签名；`-412/-352` 自动刷新会话后退避重试，不再发无签名请求
  - 取流三级降级：`x/player/wbi/playurl` → `x/player/playurl` → `fnval=0` 的 durl；同时收集 `backup_url`，缓存下载失败自动换 CDN 重试
  - 错误提示改为可操作：「建议在「B站账号」里扫码登录后重试」
- **B 站账号联动（重点）**：「我的」/「设置」新增「B站账号」页，点「打开 B 站 App 授权登录」即跳到 B 站 App 的授权确认页，点「确认」后自动完成登录（不必再找第二台设备扫码、不必输入密码）；登录态自动写入 Cookie，可解锁高码率
  - 原理：把二维码背后的网页授权链接经 `bilibili://forward?-Btarget=` 交给 B 站 App 自带 WebView，那里已是登录态；BMusic 的 2s 轮询照常接收结果。无需开放平台 `client_id` / 官方 SDK，仍零第三方依赖
  - 二维码仍保留作备用（另一台设备扫码）；横屏改为左右分栏，二维码完整可见
  - 登录后自动查找、没有就创建名为 **bmusic** 的收藏夹；在 B 站 App 里把视频收藏进去，回到 BMusic 点「从 bmusic 收藏夹导入歌曲」即可批量入库（合集展开全部视频、多 P 全部分 P 导入，已存在的曲目跳过且保留缓存/播放次数）
  - 支持退出登录（仅清除本机凭证，不动曲库与缓存）
- **「+」号新增导入入口**：曲库右上「+」的第 5 项「从 B 站收藏夹导入（bmusic）」，点一下直接开始导入；未登录先走授权，授权完成自动接着导入；横屏下 5 项用紧凑行高完整显示
- **合集 / 多 P 全量导入**：收藏夹里的视频合集（`type=21`，只有 season_id 没有 bvid）经 `seasons_archives_list` 分页展开全部成员视频；多 P 视频不再只取第 1 P，复用一次 `view` 数据把所有分 P 入库；已存在曲目跳过且保留缓存/播放次数
  - 登录后隐藏横屏残留的空登录卡片，页面更整洁

## 功能一览
- 把 B 站视频当音乐听：分享 / 粘贴链接 → 自动解析并入库
- 本地缓存，离线优先播放；无缓存时实时从 B 站拉取音频流
- 后台播放（前台服务）+ 通知栏控制 + 媒体按键 / 耳机拔插控制
- 曲库 / 歌单 / 最近播放 / 我的 四视图，支持歌单与播放队列，可按歌手 / 专辑筛选
- 播放队列独立页：标记正在播放，支持上移 / 下移 / 移除等操作
- 在线歌词：自动搜索 + 逐行同步高亮，支持手动搜索更换（预填歌手+歌名）
- 竖向音量条：播放页右侧，显示与调节一体
- 模糊封面背景、类音乐播放器界面
- 适配分屏与自由窗口：窗口尺寸变化时自动重排内容
