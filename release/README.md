本目录存放可直接下载安装的 APK 成品，随仓库一起推送，方便从 GitHub 直接获取。

## 当前版本

- **版本号**：v1.0.23（`versionName 1.0.23` / `versionCode 24`）
- **包名**：`com.volcano.bmusic`
- **最低系统**：Android 7.0（API 24）
- **目标系统**：Android 14（API 34）
- **体积**：约 255 KB（零第三方依赖，纯 Android SDK 构建；含 ZXing QR 解码子集）
- **APK 文件**：[`bmusic.apk`](bmusic.apk)（本目录内，始终为最新版）

### v1.0.23 更新内容
- **修复列表标题「有的居中有的左对齐」随机错乱**：根因是行复用时跑马灯用上一条内容的旧宽度评估，且 gravity 初始状态与 XML 默认不符导致首次居中被守卫跳过——是否居中竟取决于该行的复用历史
- **播放页按钮跑马字不再贴边/出界**：留白从文字移到按钮容器上，滚动中的文字会在距药丸边缘 12dp 处被干净裁切
- 现在：放得下的标题稳定居中，放不下的照旧往复滚动

### v1.0.22 更新内容
- **播放页按钮留白优化**：跑马灯按钮的文字与药丸边缘留出呼吸空间（左右 14dp），短文字正确水平居中
- **修复两处滚动容器细节**：居中判定只设置了垂直 gravity（水平实际靠左）；滚动终点距离计算重复叠加了 padding，导致到头后多滚一段
- **修复列表行点击被吞**：滚动容器不再消费触摸事件，标题/副标题区域的行点击、长按与迷你条点击恢复正常

### v1.0.21 更新内容

- **播放页所有按钮超宽也改为往复滚动**，不再出现省略号

### v1.0.17 更新内容

### v1.0.16 更新内容
- **扫码解码器换为 ZXing（重点）**：自研解码器只支持 v1-10 且识别率不足；现引入 ZXing core 的 QR 解码子集（Apache 2.0 开源，仅 50 个文件、只含解码所需代码），识别率与兼容性对齐主流扫码 App
- **体积只增 33KB**（218→251KB）：删掉 806 行旧解码器，仅 vendored 解码所需类
- **识别策略**：全局直方图二值化 → 局部自适应（Hybrid）→ 反色重试，白底黑码 / 深底白码都能识别
- 已验证：JVM 样张（v3-v8、四种纠错级、长链接）+ Note8 相册识别真码端到端导入成功

### v1.0.15 更新内容
- **专辑校准源换为 QQ 音乐**：网易云搜索翻唱太多、专辑字段常是合集名（如「书生尘唱的流行歌」）；QQ 音乐返回真实发行专辑——实测「路」→《丝路》、《完整的我》→《好吗？－太阳如常升起》、《天灯》→《静茹 & 情歌 别再为他流泪》
- **存量专辑自动重取**：升级后首次启动清空旧专辑（可能来自网易云的错误结果）并重新联网补齐（`backfill v5`）；标题里明确写了「专辑：xxx」的不受影响
- **门控不变**：歌名一致 + 歌手对得上才采纳，否则留空显示 `Unknown`，绝不张冠李戴
- 说明：曾考虑百度百科（信息最权威），但百科站有 JS 反爬校验，纯 HTTP 客户端无法访问，故选用 QQ 音乐公开搜索接口

### v1.0.14 更新内容

## 下载与安装

### 方式一：本仓库文件直链（始终最新）
手机浏览器打开下面任意一个链接，下载后允许「安装未知来源应用」即可安装：

```
https://raw.githubusercontent.com/volcanochen/bmusic/main/release/bmusic.apk
```

### 方式二：GitHub Releases 页面（带版本与下载按钮）
在仓库的 **Releases** 页（或 Tags）找到对应版本，点击 `bmusic-vX.Y.Z.apk` 下载。
Releases 页面在手机上体验更好，下载按钮更醒目。

> 提示：Android 首次安装未知来源 APK 时，系统会要求授予「允许来自此来源的应用」权限，按提示开启即可。

## 更新说明（重要）
本 APK 使用本仓库内 `debug.keystore` 签名（已随仓库提交，构建可复现）。
因此：**后续新版本覆盖安装时无需卸载旧版**，签名一致即可直接升级。

## 功能一览
- 把 B 站视频当音乐听：分享 / 粘贴链接 → 自动解析并入库
- 本地缓存，离线优先播放；无缓存时实时从 B 站拉取音频流
- 后台播放（前台服务）+ 通知栏控制 + 媒体按键 / 耳机拔插控制
- 曲库 / 歌单 / 最近播放 / 我的 四视图，支持歌单与播放队列，可按歌手 / 专辑筛选
- 播放队列独立页：标记正在播放，支持上移 / 下移 / 移除等操作
- 在线歌词：自动搜索 + 逐行同步高亮，支持手动搜索更换（预填歌手+歌名）
- 竖向音量条：播放页右侧，显示与调节一体
- 模糊封面背景、类音乐播放器界面
- 适配分屏与自由窗口：窗口尺寸变化时自动重排内容

## 构建（如需自行编译）
环境：Android SDK（build-tools 34.0.0）、JDK 17（Android Studio 自带）。
免 Gradle，纯 SDK 工具链：

```bash
cd bmusic
bash build.sh                 # 产物在 build/bmusic.apk
cp build/bmusic.apk release/bmusic.apk
```
