# BMusic 发布包（release）

本目录存放可直接下载安装的 APK 成品，随仓库一起推送，方便从 GitHub 直接获取。

## 当前版本

- **版本号**：v1.0.7（`versionName 1.0.7` / `versionCode 8`）
- **包名**：`com.volcano.bmusic`
- **最低系统**：Android 7.0（API 24）
- **目标系统**：Android 14（API 34）
- **体积**：约 160 KB（零第三方依赖，纯 Android SDK 构建）
- **APK 文件**：[`bmusic.apk`](bmusic.apk)（本目录内，始终为最新版）

### v1.0.7 更新内容
- **新增「返回 B 站」**：曲目列表操作菜单（曲库 / 最近 / 歌单 / 队列）与播放页底部均可一键跳回
  B 站该曲目的视频页面；多 P 视频自动定位到对应分 P（`?p=N`）
  - 打开方式由系统分发：可选择浏览器或 B 站 App

### 需求全集
所有历史需求与实现对照见 [docs/requirements/README.md](../docs/requirements/README.md)。

### v1.0.6 更新内容
- **歌词搜索栏智能预填**：自动填入「歌手 歌名」，去掉 P1 / 第N集 / BV号等编号噪声，不再混入 UP 主名
- **播放队列独立成页**：播放页底部「播放队列」按钮进入，按曲库样式展示，正在播放的曲目 ▶ 标记
  - 支持立即播放 / 上移 / 下移 / 缓存到本地 / 加入歌单 / 从队列移除 / 删除曲目
- **「立即播放」语义修正**：加入当前播放列表（不在队列则插入当前曲之后）并立即播放
- **曲库新增批量播放**：「播放 N 首」按当前筛选范围全部导入播放列表并播放，不打断正在听的歌
- **迷你条播放事件提醒**：缓冲中 / 播放中 / 已暂停状态 + 进度线，标题切换淡入淡出过渡动画
- **修复冷启动后播放队列为空**：进程被杀后首次进入时服务未运行导致队列页空白，现在按需唤醒服务恢复队列

### v1.0.5 更新内容
- **适配分屏 / 浮窗（自由窗口）**：窗口尺寸变化时重新排版，内容按可用空间自适应
  - 按窗口宽高比自动切换竖屏 / 横屏布局（不再依赖整机方向）
  - 封面、音量条、播放控制按钮随窗口高度缩放，小窗口自动进入紧凑模式
  - 底部操作按钮（缓存 / 加入歌单 / 歌词）在空间不足时自动去掉图标、禁止换行
  - 切分屏 / 拖动浮窗时**不重建 Activity**（保留播放与歌词面板状态）

### v1.0.4 更新内容
- **新增歌词**：联网自动搜索并展示歌词，播放时逐行高亮、自动滚动同步；歌词面板顶部可手动搜索 / 更换歌词
- **新增竖向音量条**：位于播放页右侧，既是音量显示条也是调节条，拖动即时改变媒体音量
- 「缓存到本地」按钮整合状态与进度：按钮内直接显示下载百分比与速度
- 曲库点击不再自动播放（改为加入队列），播放为显式操作
- 修复应用重启后点击播放无反应的问题（播放器未就绪时自动重新准备）
- 修复编译错误被静默吞掉导致「一打开就闪退」的问题（构建脚本加固）

### v1.0.2 更新内容
- 适配屏幕旋转：竖屏 / 横屏自动切换布局，播放不中断
- 修复播放页按钮状态与进度条不刷新问题
- 修复 Android 13+ 动态注册广播导致的崩溃

## 下载与安装

### 方式一：本仓库文件直链（始终最新）
手机浏览器打开下面任意一个链接，下载后允许「安装未知来源应用」即可安装：

```
https://raw.githubusercontent.com/volcanochen/bmusic/main/release/bmusic.apk
```

### 方式二：GitHub Releases 页面（带版本与下载按钮）
在仓库的 **Releases** 页（或 Tags）找到对应版本，点击 `bmusic-vX.Y.Z.apk` 下载。
Releases 页面在手机上体验更好，下载按钮更醒目。

> 提示：Android 首次安装未知来源 APK 时，系统会要求授予「允许来自此来源的应用」权限，按提示开启即可。

## 更新说明（重要）
本 APK 使用本仓库内 `debug.keystore` 签名（已随仓库提交，构建可复现）。
因此：**后续新版本覆盖安装时无需卸载旧版**，签名一致即可直接升级。

## 功能一览
- 把 B 站视频当音乐听：分享 / 粘贴链接 → 自动解析并入库
- 本地缓存，离线优先播放；无缓存时实时从 B 站拉取音频流
- 后台播放（前台服务）+ 通知栏控制 + 媒体按键 / 耳机拔插控制
- 曲库 / 最近播放 / 我的 三个视图，支持歌单与播放队列
- 播放队列独立页：标记正在播放，支持上移 / 下移 / 移除等操作
- 在线歌词：自动搜索 + 逐行同步高亮，支持手动搜索更换（预填歌手+歌名）
- 竖向音量条：播放页右侧，显示与调节一体
- 模糊封面背景、类音乐播放器界面
- 适配分屏与自由窗口：窗口尺寸变化时自动重排内容

## 构建（如需自行编译）
环境：Android SDK（build-tools 34.0.0）、JDK 17（Android Studio 自带）。
免 Gradle，纯 SDK 工具链：

```bash
cd bmusic
bash build.sh                 # 产物在 build/bmusic.apk
cp build/bmusic.apk release/bmusic.apk
```

## 校验
安装前可核对 APK 大小（约 139–140 KB）与包名，确保来源为本仓库。
